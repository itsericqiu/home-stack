# Session Handoff Template

- Summary: what was accomplished in this session
- Decisions: list decisions made, with rationale
- Open tasks: what remains to be done
- Per-host context: host, environment, tokens used (redacted in repo)
- Next steps: explicit steps for the next agent
- Attachments: links to relevant files in the repo
- Risk notes: known risks and mitigations

Usage: Fill this template at the end of a session to hand off to the next maintainer/agent.
