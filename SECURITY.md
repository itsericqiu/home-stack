# Security Policy

home-stack is a personal project maintained by one person, on their own time.
There is no bug bounty and no SLA on response time.

If you find something that looks exploitable (a way to bypass the identity
layer, leak secrets, or reach a service that should be tailnet-only), report
it privately via GitHub's "Report a vulnerability" (Security tab), which opens
a private advisory. Please do not open a public issue for a suspected
vulnerability.

The security model is documented in `docs/SECURITY_MODEL.md`.
